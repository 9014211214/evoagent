# Counterfactual Failure Attribution

## Goal

Do not directly convert every failure into model training data. The system proposes layer-specific hypotheses and tests them using controlled interventions.

## Causal evidence rule

An experiment supports a root-cause hypothesis only when:

```text
baseline execution        = FAIL
single-layer intervention = PASS
all other variables       = FIXED
```

A model prediction alone is not treated as verified attribution.

## Experiment matrix

| Suspected layer | Controlled intervention | Other variables held fixed |
|---|---|---|
| Skill | Replace with oracle skill | model, route, tool, context, verifier, environment |
| Router | Force known-correct route | model, skill content, tool, context, verifier, environment |
| Tool | Replay known-good tool contract/call | model, skill, route, context, verifier, environment |
| Context | Supply complete required context | model, skill, route, tool, verifier, environment |
| Verifier | Re-evaluate with oracle verifier | execution result and all runtime inputs |
| Environment | Reset or replace environment | model, skill, route, tool, context, verifier |
| Model | Replace current model with reference model | every external layer |

## Model gate

`TRAIN_MODEL` is the most expensive and highest-regression intervention. It is allowed only if:

1. the reference-model experiment changes failure to success;
2. skill, router, tool, context, verifier, and environment experiments were all executed;
3. none of those cheaper external interventions explains the failure.

Incomplete evidence returns `UNKNOWN -> ESCALATE`.

## Conflicts and multi-fault cases

If multiple interventions independently appear causal with similar confidence, attribution is considered conflicting. If multiple faults are simultaneously active and no single intervention restores success, the result is also unknown. v0.2 escalates both cases rather than mutating stable artifacts.

## Synthetic fault injection

`SyntheticCounterfactualRunner` provides deterministic scenarios for skill, router, tool, context, verifier, environment, and model faults. It is a test harness, not evidence that the same accuracy will hold on real benchmarks.

## Limitations

- The current hypothesis set is fixed rather than generated by an LLM planner.
- Counterfactual fidelity depends on the environment adapter.
- Interacting multi-layer failures require later combinatorial experiment planning.
- Confidence values are evidence weights, not calibrated probabilities.
