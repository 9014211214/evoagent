## Implemented control boundaries

### Composite snapshots

- immutable Skill and local-policy bindings;
- one active composite pointer;
- direct-parent and contiguous-round lineage;
- exactly one component change per child;
- frozen Runtime, Tool, verifier, Task and budget contracts;
- optimistic revision and independent commit actor;
- exact retry as read-only;
- audit hash chain, checkpoint and semantic replay.

### Composite evaluation

- frozen Task IDs and tracks;
- derived track and composite scores;
- derived safety, regression and resource totals;
- independent evaluator and stop decider;
- CONTINUE, STOP and ESCALATE recomputed from the persisted policy;
- no later round after a terminal decision;
- persistent evaluation/decision audit chain.

### Mixed-track Supervisor

- unique successful Skill counterfactual routes to `UPDATE_SKILL`;
- unique successful reference-policy counterfactual routes to local policy;
- ambiguous, unsafe or untrusted evidence escalates or quarantines;
- one exact Skill Case per Skill execution;
- complete pending local-policy evidence batch per policy execution;
- persistent claim/result lifecycle with optimistic run revisions;
- crash recovery and exact read-only retry;
- terminal decision must target the active composite snapshot and executed round.

### Real governed executors

- canonical controlled S0 Skill and real Skill Registry promotion;
- real deterministic local Agentic-RL numeric optimization;
- running Program Generation attestation anchored to Program and Campaign audit
  checkpoints;
- recursively verified native package projection;
- schema/runtime attestation and independent evidence acceptance;
- v2.2 Promotion-only lifecycle with two approvals and explicit local-policy
  pointer activation;
- rollback readiness retained;
- no foundation-model weights are modified.

### Evidence package and restart

- embeds integrated, composite and evaluation histories;
- embeds governed Skill state;
- embeds accepted Program/local-RL evidence;
- embeds v2.2 Promotion evidence;
- rejects coherent outer-rehash attacks and audit-tail truncation;
- exact export is read-only and conflicting files are not overwritten;
- second Lab invocation must be read-only, including optimizer non-reentry.
