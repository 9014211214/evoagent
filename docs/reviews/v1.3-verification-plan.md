# v1.3.0 Verification Plan

This review plan is evidence for a private research milestone. It is not authorization to publish, deploy, train, or execute paid work.

## Exact source gate

The merge head must satisfy:

```bash
python scripts/validate_v1_source.py
```

Required version:

```text
1.3.0
```

## Test matrix

Run the complete suite on:

```text
Python 3.11
Python 3.12
```

The suite must include:

- all v0.1–v1.2 regressions;
- all seven executable single-layer scenarios;
- frozen-Task equality for Context replays;
- Skill vs Router distinction;
- Tool vs Environment distinction;
- Verifier false-negative control;
- Model external-layer exclusion gate;
- Skill+Router ambiguity escalation;
- bounded Ticket target and evidence checks;
- no automatic Environment Ticket;
- no model training or deployment.

## Source examples

Every offline example must pass, including:

```bash
python examples/executable_cross_layer_matrix.py
python examples/automatic_local_tool_evolution.py
python examples/local_tool_evolution_lab.py
python examples/reference_evolution_lab.py
```

## Wheel validation

Build and install a clean Wheel, then verify:

- package version is `1.3.0`;
- public Runtime and Lab imports work;
- the complete cross-layer matrix executes from the Wheel;
- the matrix is repeatable;
- Environment and conflict cases have no mutation Ticket;
- Model dispatch produces `TRAIN_MODEL` only;
- external execution remains false;
- `pip check` passes.

## Compliance and claims

- five pinned third-party records must verify;
- no upstream source is copied into the core;
- no credential or hidden reasoning enters evidence;
- synthetic results are described only as lifecycle and causal-control validation;
- no official benchmark score is claimed.

## Merge rule

Merge only after ordinary read-only CI succeeds on the exact PR head. Use squash merge and bind the operation to the expected head SHA.
