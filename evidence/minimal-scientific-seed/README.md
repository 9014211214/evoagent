# Minimal scientific seed evidence

This directory contains a public aggregate summary of the first complete
externally executed frozen A0-to-A4 seed. The source result was generated from
public commit `3f3e85b188ac6ecbb4734053ed5615da89d2e889`, admitted by the strict offline
importer, and independently re-imported with the same receipt hash.

The retained controller artifact is not copied here. The summary binds its
GitHub artifact digest, source-result SHA-256, result evidence hash and strict
import-receipt hash. It contains no API credential, raw prompt, raw response,
Tool arguments or trajectory.

The evidence scope is intentionally narrow: this is one seed on 12 public
synthetic Tasks across five frozen snapshots. It verifies the controlled
Full-Agent mechanism and its accounting/import path. It is not SkillEvolBench,
SEAGym, Terminal-Bench, an official submission, a leaderboard result, a
comparison against another Agent, or multi-seed statistical evidence.
